# 问证｜跨境询盘审阅台

[在线体验](https://liu7866.github.io/wenzheng-inquiry-desk/) · [协创者号作品主页、海报与实录](https://www.synnovator.com/liu688/wenzheng-inquiry-desk)

在浏览器中分析中英文询盘、核对型号和起订量、查阅模拟阶梯价格，导出含证据版本和待办的审阅记录。输入留在当前浏览器页面。

可下载 [示例目录](catalog-example.json) 并在页面的“价格、来源与本地目录导入”中载入。试试输入 `Please quote 300 units of WL-20.`，预期示例单价为 USD 5.75。
